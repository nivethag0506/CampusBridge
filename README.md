# CampusBridge

CampusBridge is a centralized digital campus platform that connects students, alumni, faculty, placement cell, clubs, and recruiters through a single web application.

The project is being developed using a documentation-first approach where product requirements, architecture, database design, and APIs are finalized before implementation. This repository currently contains the planning and design artifacts for the project.
